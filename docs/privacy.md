# Политика конфиденциальности GestureControl (черновик)

_Версия 3 от 22.10.2026 (этап 3: обученная модель, свои жесты, логгер обучения). Приложение для личного некоммерческого использования. Черновик._

## Коротко

GestureControl использует фронтальную камеру, чтобы распознавать жесты руки. **Всё распознавание происходит на устройстве.** Видео и фотографии не сохраняются, не передаются по сети и не покидают телефон. У приложения нет разрешения на доступ в интернет.

## Какие данные обрабатываются и зачем

| Данные | Зачем | Где хранится | Сколько хранится |
|---|---|---|---|
| Кадры с фронтальной камеры | Найти руку и вычислить 21 точку (координаты суставов) | Только в оперативной памяти | Кадр удаляется сразу после анализа (миллисекунды) |
| Координаты точек руки | Распознать жест (свайп, ладонь, щипок, два пальца) и двигать курсор | Только в оперативной памяти | Около одной секунды скользящего окна |
| Название приложения на экране (имя пакета) | Включать камеру только в выбранных вами приложениях и применять зоны этого приложения | Только в оперативной памяти | До следующей смены приложения |
| Список окон на экране (идентификатор и тип окна) | Найти активное окно для проверки защищённых окон | Только в оперативной памяти | Не хранится |
| Признак «окно защищено от снимков» (да/нет) | Предупредить, что нажатие в защищённом окне может не сработать | Только в оперативной памяти | До смены окна |
| Список выбранных вами приложений | Ваши настройки | Локальная база данных на устройстве | Пока вы не удалите приложение или его данные |
| Зоны экрана (прямоугольники и назначенные действия) для каждого приложения | Ваши настройки | Локальная база данных на устройстве | Пока вы не удалите зону, приложение или его данные |
| Калибровка курсора (6 чисел) и настройки курсора | Ваши настройки | Локальное хранилище на устройстве | Пока вы не сбросите калибровку или не удалите данные |
| Настройки (например, энергосбережение, выбор классификатора) | Ваши настройки | Локальное хранилище на устройстве | Пока вы не удалите приложение или его данные |
| Свои жесты: 3–5 записанных повторов в виде **нормализованных координат точек** (без изображений), название, действие | Распознавать ваши жесты | Локальная база данных на устройстве | Пока вы не удалите жест, профиль или данные приложения |
| Записи логгера обучения: координаты точек руки и метка жеста (без изображений) | Дообучение модели на ваших данных — только если вы сами включили запись | Файлы в папке приложения (`Android/data/com.gesturecontrol/files/training`) | Пока вы их не удалите |
| Файл экспорта жестов (JSON с координатами повторов и действиями) | Перенос жестов между устройствами / резервная копия | Там, куда вы сами его сохранили | Под вашим контролем |

## Чего приложение не делает

- Не записывает и не сохраняет видео или фото.
- Не отправляет данные на серверы: в приложении нет сетевого доступа, аналитики и рекламы.
- Не распознаёт лица и не идентифицирует людей. Модель находит только кисть руки.
- Служба специальных возможностей не читает содержимое экрана, вводимый текст и уведомления (подробнее ниже).

## Служба специальных возможностей

Перед переходом в системные настройки приложение показывает отдельный экран с объяснением, что делает служба. Включить её можно только вручную в настройках Android.

Что служба делает:
- **Определяет приложение на экране** по событиям смены окна: использует только имя пакета и имя класса окна.
- **Показывает курсор** поверх экрана. Окно курсора не перехватывает касания.
- **Выполняет нажатия, долгие нажатия, прокрутку** (`dispatchGesture`) и системные действия «Назад», «Домой», «Недавние», «Шторка», но только в ответ на ваш жест рукой в выбранном приложении.
- **Проверяет защищённые окна (Android 14+).** Чтобы предупредить, что нажатие может не сработать, служба запрашивает у системы снимок активного окна (`takeScreenshotOfWindow`):
  - если окно защищено (`FLAG_SECURE`), система отказывает, и этого признака достаточно;
  - если снимок получен, буфер изображения **сразу закрывается, не читаясь**: пиксели не анализируются, не сохраняются и не передаются;
  - проверка выполняется не чаще одного раза в 1,5 с и только когда вы делаете нажатие.

Технически служба объявляет право получать содержимое окон (`canRetrieveWindowContent`): оно требуется системой для списка окон. Приложение использует из этого списка **только идентификатор и тип окна** и не обращается к тексту и элементам интерфейса.

## Камера

- Камера работает, только когда включено «Управление жестами» и на экране открыто приложение из вашего списка. В остальное время камера выключена.
- Пока камера работает, Android показывает индикатор камеры, а в шторке висит постоянное уведомление с кнопкой «Стоп».
- Кадры анализируются моделью MediaPipe Hand Landmarker, которая входит в приложение и выполняется локально.

## Обученная модель

Модель распознавания поз (`pose_mlp.tflite`) обучена на открытых датасетах (HaGRIDv2, IPN Hand; см. `docs/datasets.md`) **на компьютере разработчика** и поставляется внутри приложения. На телефоне модель только выполняется: она получает 42 числа (координаты точек руки) и возвращает вероятности поз. Данные с телефона для обучения не отправляются; дообучение на своих записях выполняется вручную: вы сами переносите файлы логгера на компьютер.

## Действия своих жестов

Свои жесты могут запускать: медиаклавиши, громкость, системные действия и скриншот (через службу специальных возможностей — снимок делает система, приложение его не получает), фонарик, яркость экрана (нужно разрешение «Изменение системных настроек»), запуск выбранного приложения, широковещательный intent для Tasker (действие intent задаёте вы; данных о руке в нём нет).

## Отладочная запись (только для разработки)

На экране отладки есть кнопка «Записать точки». Она сохраняет **только координаты точек руки** (числа), а не изображение, в CSV-файл в папке приложения на устройстве (`Android/data/com.gesturecontrol/files/recordings`). Файл никуда не отправляется. Его можно удалить вручную или вместе с данными приложения.

## Ваш контроль

- Отключить управление жестами: переключатель на главном экране или кнопка «Стоп» в уведомлении.
- Отозвать доступ к камере: Настройки → Приложения → GestureControl → Разрешения.
- Отключить службу специальных возможностей: Настройки → Специальные возможности.
- Удалить все данные: удалить приложение или очистить его данные в настройках системы.
